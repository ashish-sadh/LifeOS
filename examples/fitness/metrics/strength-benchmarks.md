## e1RM calculator

Epley formula: `e1RM = weight × (1 + reps / 30)`

Example: 75 kg × 5 reps → 75 × (1 + 5/30) = 75 × 1.167 = 87.5 kg e1RM

Use this consistently so numbers are comparable across testing sessions.

---

## Notes on this file

- Only update when you have a meaningful new data point (end of block, post-deload, after a clear PR)
- Don't update after every session — weekly fluctuations create noise
- Coach will flag when a lift has plateaued for 3+ weeks (time to change stimulus, not just add weight)
